Python Mini Games

A collection of five beginner-friendly games built with Python as part of my programming learning journey.

Games Included

1. Mad Libs – Creates funny stories using words entered by the player.
2. Dice Game – A dice competition between the player and the computer.
3. Rock Paper Scissors – The classic game against the computer.
4. Python Quiz – Tests basic Python programming knowledge.
5. Hangman – A word-guessing game using Python-related words.

Concepts Practiced

- Variables and data types
- User input and output
- Conditional statements
- For and while loops
- Functions and return values
- Lists and dictionaries
- Random module
- Exception handling (try and except)
- Sets
- String methods
- Basic problem-solving

Requirements

- Python 3.8 or later
- No external libraries required

How to Run

Open a terminal inside this folder and run any game:

bash
python mad_libs.py
python dice_game.py
python rock_paper_scissors.py
python quiz.py
python hangman.py


 Purpose

This project is part of my journey to improve my Python programming skills through practical projects and consistent learning.
