# Python Learning

Welcome to my Python learning repository.

This repository contains beginner Python projects that I built while learning Python programming.

## Projects

### 1. Calculator
A menu-driven calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

### 2. Student Profile Manager
A program that:
- Collects student information
- Stores the information in a dictionary
- Displays the profile
- Saves the profile to a text file
- Reads the saved profile from the file

### 3. To-Do List App
A program that:
- Allows users to add multiple tasks
- Stores tasks in a list
- Saves tasks to a file
- Displays saved tasks

### 4. Grade Checker
A program that accepts a student's score and displays the corresponding grade.
